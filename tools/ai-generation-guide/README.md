# 🎨 AI 魔法畫布與時光機：文字生成圖片與影音的奇幻探險

> 專為課堂教學設計的生成式 AI（Text-to-Image / Text-to-Video）視覺化互動教學簡報網頁。

---

## 📖 簡報特色與亮點

1. **一目瞭然的視覺化設計**：
   - 採用星空漸層、卡片式閱讀、大字體與生動 Emoji，降低認知負荷。
   - 支援投影幕 16:9 全螢幕模式（`⛶ 全螢幕` 按鈕或鍵盤快捷鍵）。
2. **生動貼切的原理比喻**：
   - **文字生圖（擴散模型）**：比喻為「除霧魔法」與「大理石雕刻家」，從電視雪花雜訊中辨識形狀擦出作品。
   - **文字生片（時空一致性）**：比喻為「手翻書（1秒24格）」＋「時間注意力記憶」，防止小動物中途變形融化。
3. **沉浸式互動體驗（零外部依賴、純前端）**：
   - 🎛️ **除霧滑桿模擬器**：學生可親自拖動滑桿，觀察雜訊從 100% 變為 0% 露出高清小貓的過程。
   - 🧪 **五星咒語大調配室**：互動式積木點選「主角＋動作＋場景＋風格」，一鍵生成並複製高階 Prompt。
   - 🏆 **闖關小測驗**：3 道檢定題，答對即時噴發彩帶紙花（Confetti）與勝利音效。
   - 🔊 **Web Audio 內建音效**：無需任何外部音檔即可發出柔和反饋音效，可隨時靜音。
   - 🖨️ **一鍵輸出講義**：支援 `window.print()`，可直接另存為 A4 彩色列印講義或 PDF。
