# 座標獵人（Coordinate Hunter）

直角坐標平面（Cartesian Coordinate System）互動教學小遊戲，適合國中數學第一冊第三章、國小高年級座標概念教學與課堂投影互動。

## 🎯 教學目標

- 熟練辨識直角坐標平面上的 X 軸、Y 軸、原點 $(0, 0)$。
- 正確理解並找出點坐標 $(x, y)$ 在平面上的位置（先看 X 水平位移，再看 Y 垂直位移）。
- 理解並判斷四個象限：
  - 第 Ⅰ 象限 $(+, +)$
  - 第 Ⅱ 象限 $(-, +)$
  - 第 Ⅲ 象限 $(-,-)$
  - 第 Ⅳ 象限 $(+, -)$
  - 坐標軸上的點（X 軸上的點 $y=0$、Y 軸上的點 $x=0$）

## 🎮 三種遊戲練習模式

1. **🎯 模式一：看座標抓目標**
   - 題目給定 $(x, y)$ 坐標數值，玩家在網格上直接點擊對應交叉點進行捕捉。
   - 游標懸停時即時顯示當前座標與輔助投影線，方便學生建立空間投影概念。
2. **🔍 模式二：看目標報座標**
   - 平面上出現目標紅點，學生輸入 X 與 Y 的數值後送出。
3. **🧭 模式三：象限大考驗**
   - 給定點位，學生判斷屬於「第 Ⅰ ~ Ⅳ 象限」、「X 軸上」、「Y 軸上」或「原點」。

## 🏫 班級教學友善功能

- **座號登記排行榜**：純使用「座號」，不儲存任何學生真名或個人隱私，成績保存在各設備的 LocalStorage。
- **大螢幕高對比視覺**：清楚標記象限名稱、符號與主要格線。
- **內建 Web Audio 音效**：不需要任何外部音訊檔案，提供答對連擊加成音效與防呆提示。
- **平板與觸控支援**：支援 Touch 事件，學生可在 iPad / Chromebook 上直接手動點擊答題。

## 🚀 執行方式

直接在任何現代瀏覽器開啟 `index.html` 即可使用，不需任何伺服器建置或 npm 安裝。
