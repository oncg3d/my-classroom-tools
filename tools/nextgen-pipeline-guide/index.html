🎯 什麼是「次世代（Next-Gen）」遊戲美術？

  • 即時運算（Real-time）的極限平衡： 電影動畫可以花費數小時渲染單一畫格，但遊戲引擎必須在 16.6ms（60 FPS）甚至 8.3ms（120 FPS）內，即時計算幾何體、光影、動態與物理碰撞。
  • 維度壓縮的核心魔法： 傳統手繪模型依賴美術畫死光影；次世代模型則透過 高低模雙軌流水線，將數千萬面高模的光影法線「烘焙」於數萬面的低模貼圖上，以假亂真。
  • PBR 物理渲染與物理材質： 依照光學能量守恆與微表面散射定律，讓同一個角色資產在沙漠烈日、地底火把與夜間霓虹燈下，皆呈現精確無瑕的材質質感。

Phase 01 Maya • Blender • PureRef • Photoshop

概念設定、比例剪影與基礎大型 (Blockout)

打造角色靈魂的第一步：正交視圖、剪影識別度與人體解剖學標準

📐 基礎大型（Blockout）的三大黃金法則

  • 1. 剪影第一原則（Silhouette First）： 在遠距離戰鬥或快節奏動作遊戲中，玩家依靠 純黑剪影 區分角色職業、威脅等級與動作狀態。如果把材質顏色全關掉後角色難以辨認，設計便已失敗。
  • 2. 警惕原畫正交視圖的透視陷阱： 2D 原畫常有「透視詐欺」（左側視圖與正面視圖手臂長度對不上）。3D 美術師不可盲目貼圖描邊，必須依據 真實骨骼關節位置 建立解剖基準。
  • 3. A-Pose vs T-Pose 的工程抉擇： 次世代角色推薦採用 A-Pose (手臂下垂 45°、手掌微內扣)，能最大程度減少肩膀三角肌拉伸變形，並讓手臂內側布料垂墜更自然。

Phase 02 ZBrush • Marvelous Designer • Blender Sculpt

高模雕刻（High-Poly）：解剖學、布料與微表面

動輒數千萬面的極致細節工藝：從宏觀骨骼肌理到微觀皮膚毛孔

🗿 數位雕刻的三級細節階層理論

  • 一級形體（Primary Forms - 60% 權重）： 人體骨骼突起（鎖骨、髂棘、顴骨）、主要肌肉群輪廓、頭型。此階段禁止進入高階細分，使用 Move / ClayBuildup 筆刷反覆推敲。
  • 二級形體（Secondary Forms - 30% 權重）： 肌肉交接溝槽、脂肪堆積摺疊、皮帶勒肉張力、厚重布料的大摺皺（管狀摺、折疊摺）。
  • 三級形體（Tertiary Forms - 10% 權重）： 微觀皮膚毛孔、嘴唇乾裂紋、皮件微磨損、金屬鑄造毛刺。可使用 Alpha 筆刷 或由 Substance 3D Painter 表面紋理替代。
📐 觀念圖解：三級雕刻細節金字塔與時間精力分配權重

Phase 03 TopoGun 3 • Maya Quad Draw • Blender RetopoFlow

反拓撲（Retopology）：四邊面與動畫變形布線

為什麼千萬面不能進引擎？從幾何頂點計算到關節彎曲三大定律

🕸️ 動畫拓撲的黃金布線三大定律

  • 1. 全四邊面原則（All-Quads Mesh）： 雖然遊戲引擎底層最後會將面自動三角化（Triangulation），但拓撲時堅持純四邊面，才能確保 Catmull-Clark 平滑細分、UV 展開與骨骼權重插值不出現破面裂痕。嚴禁五邊以上多邊面（N-Gons）！
  • 2. 關節三環線法則（The 3-Loop Rule）： 膝蓋、手肘、手指等單向鉸鏈關節，彎曲處必須配置 至少三條緊密環形布線。彎曲時外側拉伸、內側擠壓，才能防止關節塌陷宛如漏氣氣球。
  • 3. 臉部表情同心圓環線（Facial Loops）： 眼眶（眼輪匝肌）、嘴唇（口輪匝肌）、鼻唇溝法令紋必須呈現完整的放射同心圓環線，支援開口笑、眨眼等 52 種 Blendshape 表情變形。

Phase 04 RizomUV • Maya UV Toolkit • Blender UV

拆 UV 與紋素密度（Texel Density, TD）

將 3D 空間剝皮攤平成 2D 平面：接縫隱藏、拉伸檢驗與空間利用率極限優化

🗺️ UV 拆解工程四大核心原則

  • 1. 切縫（Seams）的隱藏藝術： 切縫應隱藏在玩家最不易察覺的死角：手臂與大腿內側、頭髮遮蓋處、衣物天然接縫、鞋底凹槽。
  • 2. 硬邊必切原則（Hard Edges Must Cut）： 幾何法線的硬邊（Smoothing Group 分界處）絕對必須切開 UV 縫！如果硬邊沒有切 UV，烘焙法線貼圖時交界處必定會產生嚴重的黑色漸層光影髒斑。
  • 3. 紋素密度統一（Consistent Texel Density）： TD (px/cm) 代表模型每公分真實尺寸分到的像素多寡。整身貼圖若 TD 不一致，會導致「臉部毛孔模糊、皮帶釦子卻異常清晰」的失衡現象。主角臉部通常會給予 1.5~2 倍的 TD 權重。
  • 4. 留白邊距（Padding）防黑邊： UV 島（Islands）之間必須預留至少 8~16 像素間距（Padding），防止遊戲引擎在遠距離產生 Mipmap 降階採樣時將邊緣黑色背景抽入模型。
📐 觀念圖解：硬邊（Hard Edge）未切 UV 黑斑成因 ＆ 對稱疊 UV 平移 U+1

角色對稱部位（左右手、靴子）重疊 UV 以節省 50% 貼圖空間。但在送入烘焙軟體前，必須將對稱的那一半在 U 軸向平移 +1 格（U+1）！烘焙完畢後再移回，否則烘焙光線會相互重疊重影！
Phase 05 Substance 3D Painter • Marmoset Toolbag 4

物理烘焙（Baking）：維度壓縮的幾何魔法

讓數萬面低模擁有千萬面高模的光影質感：光線投射、外籠（Cage）與關鍵貼圖矩陣

🔥 烘焙的運作原理與外籠（Cage）

烘焙軟體從低模表面沿著法線方向向外發射光線（Rays），穿透並探測高模表面幾何特徵，將高模的「傾斜角度」轉譯為像素色彩：

  • 法線貼圖（Normal Map）： 採用切線空間（Tangent Space），以 RGB 色彩對應空間向量 (X, Y, Z)。淡紫色（RGB: 128, 128, 255）代表垂直於表面的朝向。
  • DirectX 格式 vs OpenGL 格式（Y 軸翻轉）： Unreal Engine 5 採用 DirectX (-Y)，而 Maya / Blender / 3ds Max 常用 OpenGL (+Y)。若發現光影凹凸顛倒，只需在 SP 導出時切換或在 UE5 勾選「Invert Green Channel」！
  • 外籠（Cage）防止光線交叉誤擊： 在手指縫、腋下、雙腿夾角處，直線發射的光線容易穿透擊中對向模型。透過在低模基礎上膨脹出的 Cage 包覆高模，即可精準引導光線射角。
🔥 觀念圖解：外籠（Cage）引導投射光線 ＆ DirectX / OpenGL 綠通道翻轉

PBR 物理渲染核心專題 Microfacet • Energy Conservation • Fresnel • Cook-Torrance BRDF

PBR 物理基礎渲染光學原理（Physically Based Rendering）

深入光與物質的交互作用：能量守恆定律、微表面散射、菲涅爾效應與金屬/非金屬物理本質

⚛️ PBR 物理渲染四大核心光學定律

  • 1. 能量守恆定律（Energy Conservation）： 出射光總能量（鏡面反射 Specular ＋ 漫反射 Diffuse）絕不可能大於入射光總能量。當物體表面越光滑、鏡面高光越強越聚攏時，穿透至內部的漫反射光必須相應減弱，杜絕舊世代遊戲中高光與漫射同時死亮的違和過曝！
  • 2. 微表面散射理論（Microfacet Theory）： 任何巨觀平整的物體，微觀下皆是由無數微小的凹凸反射鏡（Microfacets）所組成。Roughness 控制微表面法線的混亂度（GGX 分佈）。越光滑則微面朝向一致（高光銳利）；越粗糙則光線四散（高光模糊擴散）。
  • 3. 菲涅爾效應（Fresnel Effect, Schlick 近似式）： 視角決定反射率！ 正視表面時（0°）反射率最低，稱為基礎反射率 F0；但當視線與表面呈擦邊掠射角（80° ~ 90°）時，無論任何物質，反射率均會暴增至接近 100%！
  • 4. 導體與電介質的本質分野（Conductors vs Dielectrics）： 非金屬（電介質）：F0 約 4%，折射光形成豐富漫反射（BaseColor），高光呈純白無彩色。
    純金屬（導體）：F0 高達 70% ~ 100%，自由電子吞噬折射光（漫反射為 0），高光帶有 BaseColor 顏色（如黃金高光呈金黃）！因此 Metallic 貼圖必須「非黑即白」。
📐 觀念圖解：光學能量守恆與光線分流平衡式 (Energy Conservation)
💡 現代雙工作流之爭：為什麼 Metallic/Roughness 勝出？
舊式 Specular/Glossiness 允許美術隨意手繪高光顏色與強度，極易打破能量守恆；而 Metallic/Roughness 工作流將物理常數鎖死在演算法內部，既節省一張貼圖頻寬，又確保資產在任何光照下絕不破圖！

Phase 06 Substance 3D Painter • PBR Metallic/Roughness

PBR 物理材質與 Substance 3D Painter 紋理繪製

基於物理定律的光學表現：能量守恆、微表面理論與金屬/粗糙度工作流

🎨 PBR 金屬/粗糙度四大通道解析

  • Base Color / Albedo（固有色）： 純粹的物體色彩資訊。絕對禁止手繪光影或自帶環境光！ 非金屬通常反射 4% 光線；純金屬則由 Base Color 決定鏡面反射顏色。
  • Roughness（粗糙度）： 決定物體微表面平整度。值為 0.0 (純黑) 代表極致鏡面反光；1.0 (純白) 代表粗糙霧面漫反射。
  • Metallic（金屬度）： 物理上嚴格遵守「非黑即白」二值化。金屬為 1.0，塑膠/木頭/皮革/皮膚為 0.0。只有過渡邊緣生鏽或髒污灰塵才會有中間過渡值。
  • 次表面散射（Subsurface Scattering, SSS）： 光線射入皮膚、玉石或蠟燭內部，經過多次微血管散射後透射出紅潤血色。

🦴 骨骼階層與蒙皮權重三大核心觀念

  • 1. 嚴謹的骨骼階層（Bone Hierarchy）： Root 根骨骼（座標原點）➔ Pelvis（骨盆核心）➔ Spine 脊椎鏈 ➔ Neck/Head，以及兩側鎖骨與四肢鏈。關節旋轉軸（Joint Orientations）必須嚴格朝向骨骼延伸方向，禁止軸向混亂！
  • 2. 頂點蒙皮權重守恆律（$\sum w_i = 1.0$）： 每個頂點最多受 4 ~ 8 根骨骼 共同牽引。所有骨骼影響係數之和必須精確等於 1.0。未正規化（Normalized）的權重會導致模型在動畫中頂點飛散。
  • 3. 雙四元數與扭轉骨（Twist Bones）： 解決手腕旋轉 180° 時的「糖果包裝紙塌陷（Candy-wrapper artifact）」。透過在前臂增加 1~2 根 Twist 輔助骨，將旋轉扭矩均勻分散。

Phase 08 Maya • MotionBuilder • Mocap • Cascadeur

遊戲動畫製作：關鍵影格、動態捕捉與循環動作

電影鏡頭 vs 遊戲即時響應：Idle、Walk、Run 動作循環與 Root Motion 觀念

🏃 遊戲動畫的核心特性與生產標準

  • 1. 動作循環（Animation Loops）無縫銜接： 走路（Walk）、奔跑（Run）、呼吸待機（Idle）的第 1 格必須與最後一格的骨骼位姿、速度向量完全吻合，避免循環播放時出現瞬間「抽動（Popping）」。
  • 2. 原地（In-Place）vs 根骨骼運動（Root Motion）： In-Place 角色像在跑步機上原地踏步，由遊戲程式碼位移膠囊體；Root Motion 則由 Root 骨骼實際位移帶動角色，能 100% 杜絕「腳步滑步（Foot Sliding）」。
  • 3. 動態捕捉（Mocap）數據清理： 光學或慣性動捕數據導入後，需在 MotionBuilder 或 Maya 清理關節噪點（Jitter）、鎖定腳掌貼地 IK（Foot Plant），再重定向（Retargeting）至自訂骨架。

📦 ORM 貼圖通道打包（Texture Packing）黑科技

為什麼不把 AO、Roughness、Metallic 分別存成 3 張貼圖？因為 GPU 採樣器（Texture Samplers）有硬體上限，打包成單張貼圖能狂省 66% 貼圖記憶體與讀取頻寬！

業界標準 ORM 貼圖通道映射：
R 通道 ➔ Ambient Occlusion (AO) 縫隙陰影
G 通道 ➔ Roughness 粗糙度
B 通道 ➔ Metallic 金屬度
📐 觀念圖解：UE5 主材質節點網絡連線 (Material Graph Pinout)
🚨 UE5 必學關鍵設定：取消勾選 sRGB！
ORM 貼圖屬於「線性數學數據（Linear Data）」，並非視覺顏色。導入 UE5 後必須雙擊貼圖，取消勾選「sRGB」，否則粗糙度數值會被 Gamma 校正扭曲，導致材質金屬感全毀！

💣 學生初學十大致命地雷與自我診斷

1. 法線凹凸顛倒： 綠通道 Y 軸顛倒（DirectX 與 OpenGL 格式未對齊）。
2. 硬邊黑線髒斑： 模型硬邊（Hard Edge）交界處未在 UV 上切開 Seam。
3. 未凍結變換（Freeze Transforms）： DCC 軟體導出前未重置位移縮放，進引擎模型旋轉 90 度或縮放爆炸。
4. ORM 貼圖勾了 sRGB： 導致粗糙度被校正變亮，在 UE5 呈現死白無光澤。
5. 對稱烘焙重疊穿幫： 疊 UV 烘焙時忘記將對稱部分平移 U+1。
6. 關節體積塌癟： 膝蓋手肘沒有做 3-Loop 環線布線。
7. 蒙皮頂點權重未正規化： 頂點未受任何骨骼牽引或總和不為 1.0。
8. 單位尺寸不一致： Maya 預設公厘 (mm) 或公尺 (m) 未改為公分 (cm)。
